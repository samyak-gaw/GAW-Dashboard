☁️ Cloud Sync — GitHub + Netlify
Data is pushed as a JSON file to your GitHub repo → Netlify rebuilds → all viewers get fresh data within ~30 seconds. No size limits, no third-party APIs.

🐙 GitHub Auto-Deploy Sync ✅ Connected

One-time setup (5 mins):
  1. Go to github.com → create a free account if you don't have one
  2. Create a new repo (e.g. gaw-dashboard) and upload your index.html there
  3. Connect repo to Netlify: app.netlify.com → Add site → Import from GitHub → select your repo
  4. Create a GitHub Personal Access Token: github.com/settings/tokens → Tokens (classic) → Generate → check repo scope → copy it
  5. Enter token, username, repo name below → click Save GitHub Config

📅 Monthly Targets Configuration (Admin only — sets targets for the current month)

Enter targets in ₹ (e.g. 5500000 for ₹55L). Changes take effect immediately and sync to GitHub.

🔄 Viewer Sync — Pull Latest Data

Viewers can pull the latest data directly from GitHub without needing a token. Enter the GitHub username, repo name, and file path that the owner set up, then click Pull Now. The dashboard will auto-refresh every 90 seconds.
